Design & Styling Guidelines
Color Palette:

Cream White (#fcfbf7): Primary background for a warm, clean aesthetic.

Dark Charcoal / Black (#121212): Headers, footers, and crisp typography contrast.

Warm Brown (#5c4033, #d4a373): Accent colors for borders, buttons, and navigation hover states.

Soft Grey (#f4f0ea, #333333): Card backgrounds and secondary text colors.

Typography & Layout:

Standard, clean sans-serif font stack (Segoe UI, Tahoma, Geneva, Verdana, sans-serif).

Mobile-first approach using CSS Grid and Flexbox for seamless responsiveness across desktops, tablets, and mobile devices.

 How to Run the Project
Clone or Download the project folder to your local machine.

Ensure the file structure matches the layout specified in the Project Structure section.

Open index.html in any web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari) to view the site.

Navigate through the site using the top header menu.//
